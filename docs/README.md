# cortex documentation

The site at [atakang7.github.io/cortex](https://atakang7.github.io/cortex/) is built with Astro.

Use Node.js 24 and the lockfile:

```sh
cd docs
npm ci
npm run dev
```

Run `npm run build` to check the production output in `docs/dist/`. GitHub Actions publishes the site from `main`.
